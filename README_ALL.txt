CROSS-LINGUAL BIAS DETECTION

Start with README.md for the visual framework, model table, repository tree,
notebook instructions, citations, and license summary.

WORKFLOW
A. Datasets/                 Parallel English, Italian, and Persian CSV inputs
B. Language Model Tests/     Six model configurations and two order controls
C. Merging LM Responses/     Align model choices across the three languages
D. Analysis/                 Agreement, divergence, domains, entropy, and CIs

This is a Jupyter notebook workflow. Generated inference and merged response
files are not included. Read docs/REPRODUCIBILITY.md for model-specific setup,
JSON input preparation, filename mismatches, and interpretation limitations.
